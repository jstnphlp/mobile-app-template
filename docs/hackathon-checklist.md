# Hackathon readiness checklist

## Before theme
- [ ] All teammates have Flutter and device/emulator tooling.
- [ ] Generate, review and commit `android/` and `ios/` native scaffolds.
- [ ] Pick app identifiers, platform permissions and Android target.
- [ ] Confirm CI passes after platform generation.
- [ ] Agree on feature ownership and shared API contracts.
- [ ] Keep one known-good installable build and backup demo video.
- [ ] Check competition rules on prewritten starter code and AI assistance.

## After theme
- [ ] Write business context and top-level demo journey.
- [ ] Create short, independent specs and GitHub issues.
- [ ] Verify Supabase auth/row policies if a backend is needed.
- [ ] Populate synthetic demonstration data, never private records.
- [ ] Test on an actual Android device and correct network endpoint.
- [ ] Do a clean install, permission checks, and offline/error scenarios.
- [ ] Freeze feature changes before the final demo.
